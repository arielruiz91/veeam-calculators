How the calculation works

Source data

Number of machines × average used size per machine. This is the working set the backup job must protect.

Full backup size

Source data divided by the configured compression and deduplication ratio. The default of 2:1 is a typical mixed-workload assumption.

Incrementals

Each incremental approximates full × daily change rate. Restore points beyond the first full add (retention − 1) incrementals to the performance tier.

GFS & capacity tier

GFS adds weekly, monthly, quarterly and yearly fulls on the capacity tier. Move policies relocate older points off the performance tier after the operational restore window.
